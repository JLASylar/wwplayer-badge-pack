# WWPlayer white studio logos

A badge pack for WWPlayer. Some studio logos that ship with WWPlayer are black and are hard to see on dark detail pages. This pack swaps 27 of them for white versions.

Import URL (WWPlayer → Settings → badge pack):

```
https://raw.githubusercontent.com/JLASylar/wwplayer-badge-pack/main/pack.json
```

How it works:
- WWPlayer matches studio badges to pack entries by name.
- Every entry uses the regex `(?!)`, which matches nothing, so the pack never changes resolution, HDR or codec labels.

The images are the logos bundled with WWPlayer 1.3.15, recoloured to white. All trademarks belong to their owners.
